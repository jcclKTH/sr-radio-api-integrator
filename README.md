# sr-radio-api-integrator

**Sveriges Radio API Integrator**
A dynamic web interface engineered to consume and visualize real-time data from the Sveriges Radio (SR) Open API. This project demonstrates proficiency in asynchronous data fetching, JSON parsing, and DOM manipulation using vanilla JavaScript.

**Key Features**
Real-Time Data Ingestion: Fetches live radio channels, scheduled episodes, and playlist metadata directly from the SR v2 API.

Asynchronous Architecture: Utilizes modern ES6+ async/await patterns to handle multiple non-blocking API requests simultaneously.

Dynamic Audio Handling: Manages audio streams programmatically, updating sources and playback states based on user interaction.

Data Parsing: Extracts and formats complex nested JSON data (program schedules, start times, timestamps) for frontend rendering.

**Technical Stack**
Language: JavaScript (ES6+), HTML5, CSS3.

Data Source: Sveriges Radio Open API.

Core Concepts: REST APIs, JSON, Promises, Event Handling.

**How to Run**
Clone the repository.

Open sr.html in any modern web browser.

Select a channel to view the schedule and listen to the live stream.
